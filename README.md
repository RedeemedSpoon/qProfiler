qProfiler is a command profiler tool that is both quick and easy to use, with support of a few option.

**Minimal Metrics:**

*   Elapsed (Wall-Clock) Time
*   Total CPU Time
*   CPU Utilization
*   Peak Memory Usage (Max RSS)
*   Block Input Operations
*   Block Output Operations
*   Exit Status

**Default Metrics:**

*   Elapsed (Wall-Clock) Time
*   CPU Utilization
*   User CPU Time
*   System CPU Time
*   Total CPU Time
*   Peak Memory Usage (Max RSS)
*   Major Page Faults
*   Swaps
*   Block Input Operations
*   Block Output Operations
*   Exit Status

**Verbose Metrics:**

*   Elapsed (Wall-Clock) Time
*   CPU Utilization
*   User CPU Time
*   System CPU Time
*   Total CPU Time
*   Peak Memory Usage (Max RSS)
*   Major Page Faults
*   Minor Page Faults
*   Swaps
*   Block Input Operations
*   Block Output Operations
*   Voluntary Context Switches
*   Involuntary Context Switches
*   Exit Status
